Integration Guide

How to use the component in your PHP pages.

Basic Usage:

<!-- Add to your PHP page -->
<script src="path/to/alert-escalation-widget.js"></script>

<!-- Badge Mode -->
<div id="badge-widget"></div>
<script>
  const badgeWidget = new AlertEscalationWidget({
    containerId: 'badge-widget',
    mode: 'badge',
    activeLevel: 2,
    onLevelChange: (level) => {
      console.log('Alert level changed to:', level);
      // Update your backend via AJAX
    }
  });
  badgeWidget.render();
</script>

<!-- Timeline Mode -->
<div id="timeline-widget"></div>
<script>
  const timelineWidget = new AlertEscalationWidget({
    containerId: 'timeline-widget',
    mode: 'timeline',
    orientation: 'horizontal', // or 'vertical'
    activeLevel: 3,
    isInteractive: true
  });
  timelineWidget.render();
</script>

Configuration Options:

  • containerId: ID of the HTML element to render into (required)
  • mode: 'badge' or 'timeline' (default: 'badge')
  • activeLevel: Current alert level 1-4 (default: 1)
  • orientation: 'horizontal' or 'vertical' for timeline mode (default: 'horizontal')
  • isInteractive: Enable level adjustment controls (default: true)
  • onLevelChange: Callback function when level changes
