HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════

When you login:
1. login_process.php gets your credentials
2. Checks password
3. UPDATES users table: sets last_login = NOW()
4. INSERTS into activity_logs: records 'login' action
5. Logs every step to login_debug.log file
6. Redirects to dashboard

When you logout:
1. logout.php starts
2. INSERTS into activity_logs: records 'logout' action
3. Logs every step to logout_debug.log file
4. Clears session
5. Redirects to landing page
