❓ FAQ
Q: Is middle initial required?

A: No, it's optional. Users can skip it and it will be saved as NULL in the database.

Q: What happens to existing users?

A: Existing users will continue to work. Their middle_initial column will be NULL. When they login, they'll still display correctly without the middle initial.

Q: Why use NOW() instead of CURRENT_TIMESTAMP?

A: NOW() is evaluated at execution time (more accurate for immediate updates like last_login), while CURRENT_TIMESTAMP is sometimes evaluated at different times.

Q: Can I edit the middle initial after registration?

A: Currently, the system doesn't have an edit profile feature. You would need to contact an admin to modify it, or we can add a profile edit page in the future.
